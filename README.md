# pairwise-taa-history

角色快速转身后拖出一条半透明残影，重投影只用上一帧视图矩阵，没用运动矢量，转身时历史全错位；深度拒绝用固定阈值，近处角色和远处背景被同样对待；历史颜色在 tonemap 之后混合，亮部残留成白雾；遮挡关系变化时没重置历史，被墙挡住的像素一直带着旧颜色；透明物体也写入历史，玻璃后拖出鬼影；jitter 序列每帧重置，静止画面仍在闪；历史缓冲没做颜色 clamp，HDR 高光溢出到邻域；相机 cut 后没清历史，切镜第一帧整屏残影；分屏双眼共用一份历史，左眼污染右眼；动态分辨率切换后历史 UV 没重算，画面整体偏移；锐化放在 TAA 之前，残影被锐化成硬边。render/taa_history.py 是核心，tests/test_taa_history.py 15个红。要修的是：重投影用运动矢量；深度拒绝按视差分层；历史在线性 HDR 域混合；遮挡变化重置历史；透明不写历史；jitter 序列连续；历史颜色钳制；cut 清历史；双眼独立历史；分辨率变化重算 UV；锐化移到 TAA 之后。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
